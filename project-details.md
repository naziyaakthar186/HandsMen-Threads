# HandsMen Threads – Salesforce CRM Project

## Project Overview
HandsMen Threads is a Salesforce CRM project designed to manage men's fashion products, customers, orders, inventory, and loyalty programs.

## Features
- Customer and product management
- Order management and validation
- Inventory management
- Customer loyalty status based on total purchases
- Order confirmation email flow
- Low-stock alert flow
- Apex triggers for order validation, order total calculation, and loyalty status updates
- Scheduled inventory batch job

## Technologies Used
- Salesforce CRM
- Salesforce Flow Builder
- Apex
- Custom Objects and Fields
- Validation Rules
- Email Alerts
- Scheduled Apex
